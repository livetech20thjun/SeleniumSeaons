HTML Terminilogies 

<tagName attribute1="value of attribute1" ...attributen="value of attributen>

<input type="text" name="username" id="username" class="login_input" value="" fdprocessedid="003bj6">

<a href="Register.php">New User Register Here</a>


1) Xpath based on tagname and attributes 

//tagname[@attribute='value of attribute']

<input type="text" name="username" id="username" class="login_input" value="" fdprocessedid="b3qg9l">

//input[@id='username']						
						

2) Xpath based on tagName and text on element 

//tagname[text()='text on element']

<a href="Register.php">New User Register Here</a>

//a[text()='New User Register Here']


3) Xpath using contains functions

//tagname[contains(@attribute,'subset of value of attribute')]

//tagName[contains(text(),'subest of text on element')]

//a[contains(text(),'Register Here')]

<img src="img/ios-button.png">

//img[contains(@src,'ios-button')]
